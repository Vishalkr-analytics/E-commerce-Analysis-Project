# 🛒 E-commerce-Analysis-Project Dashboard | SQL + Power BI

## 📌 Project Overview
This project presents an interactive ** E-commerce-Analysis Dashboard** built using **SQL** and **Power BI**. The dataset was imported from a SQL database, cleaned, transformed, and optimized by creating views and establishing relationships before being visualized in Power BI.

The dashboard helps analyze business performance, customer behavior, sales trends, delivery performance, payment insights, and seller performance through interactive reports.

---

## 🛠️ Tech Stack

- **SQL** – Data importing, cleaning, transformation, view creation, and data modeling
- **Power BI** – Data visualization, DAX measures, dashboard development, and interactive reporting

---

## 📊 Dashboard Pages

1. **Executive Overview** – Business KPIs, revenue trends, top categories, geographic sales, and order status.
2. **Sales Trends** – Revenue comparison, YTD analysis, rolling revenue, and monthly sales performance.
3. **Category & Product Analysis** – Category performance, AOV, ratings, and revenue distribution.
4. **Customer Geography** – State and city-wise sales analysis with geographic insights.
5. **Delivery & Logistics** – On-time delivery, late orders, delivery performance, and delivery time analysis.
6. **Reviews Analysis** – Customer ratings, review distribution, and category-wise review insights.
7. **Payments Analysis** – Payment methods, payment trends, installments, and transaction analysis.
8. **Seller Performance** – Seller-wise revenue, geographic distribution, and performance metrics.
9. **Drillthrough Report** – Detailed category, seller, or region-level performance analysis.
